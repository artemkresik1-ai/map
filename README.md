# РУБІЖ

Карта — статична сторінка з Vercel-функцією `/api/dimap`, яка отримує дані
DIMAP серверно, щоб браузер не блокував запит через CORS.

Vercel має бути підключений до цього репозиторію з кореневою директорією
проєкту. Кожен push у `main` автоматично запускає нове розгортання.

GitHub Pages також можна використовувати як статичний хостинг, але без функції
`/api/dimap` DIMAP буде недоступний через CORS.
