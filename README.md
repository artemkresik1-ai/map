# Арт.Радар v6.0

Карта — статична сторінка з Vercel-функцією `/api/dimap`, яка отримує дані
DIMAP серверно, щоб браузер не блокував запит через CORS. Плитки карти
завантажуються лише з OpenStreetMap.

Vercel має бути підключений до цього репозиторію з кореневою директорією
проєкту. Кожен push у `main` автоматично запускає нове розгортання.

GitHub Pages також можна використовувати як статичний хостинг, але без функції
`/api/dimap` DIMAP буде недоступний через CORS.

## Telegram-бот

Vercel-функція `/api/telegram-webhook` відповідає лише на `/start` і `/help`
та пояснює, що Арт.Радар — неофіційна інформаційна мапа, а не канал
оповіщення. Щоб увімкнути її:

1. Відкличте будь-який токен, який уже публікувався, створіть новий у
   BotFather і збережіть його лише в менеджері секретів Vercel.
2. У Vercel додайте змінні `TELEGRAM_BOT_TOKEN` і
   `TELEGRAM_WEBHOOK_SECRET` для Production. Для webhook-секрету створіть
   випадковий рядок щонайменше з 32 символів.
3. Налаштуйте Telegram webhook на
   `https://<ваш-домен>/api/telegram-webhook` із тим самим значенням
   `TELEGRAM_WEBHOOK_SECRET`, після чого виконайте redeploy.

Не додавайте токен до HTML, JavaScript, Git або URL, які можуть потрапити в
історію браузера чи логи. Бот не надсилає попереджень про рух об'єктів.
